📖 操作手册 · V1.1.0（红利20 / 纳指30 / 黄金25 / 债25）

静态四腿 + 周定投(每周2,885) + 纳指/红利跌破250日线双倍 + 月检≥3pp再平衡｜不择时、不熔断｜满仓后永久持有
一、配置（可改）
· 目标：红利低波 20% / 纳指 30% / 黄金 25% / 债 25%——在「调仓页」可修改保存，改完自动同步定投看板与各腿偏离提示
· 场内：ETF（512890 / 513100 / 518880 / 511010）手动填 份额+成本价
· 场外：基金持仓表格导入（自动归类：红利/纳指/黄金/债，货币、004010 归债），导入后自动拉净值并上传云端
二、定投（每周，30万本金）
· 每周预算 2,885 元：红利低波 577 / 纳指 866 / 黄金 721 / 债 721（随目标配比联动）
· 智能加倍：红利低波或纳指跌破各自250日线 → 该腿×2（其余腿不变，合计相应增加）；黄金/债恒定
· 周五晚查 MA250（定投看板自动显示），周一按看板金额执行
三、场外基金导入与自动更新
· 复制「天天基金/基金E账户」持仓明细表格（代码/名称/…/持有份额/净值/资产），自动按基金代码合并重复并归类；识别不到的默认跳过
· 导入后自动拉最新净值（每天打开也会自动拉），更新市值/当日盈亏，并自动上传云端
四、满仓后（永久持有）
· 每月第一个交易日：任一腿偏离目标 ≥3pp → 调回（按「优先场内/场外」执行）
· 不择时、不熔断
五、纪律（最重要）
1) 危机期（回撤>20%）禁止卖出：只允许按计划定投或用新增资金买入
2) 每年一次基本面复核（纳指估值/黄金逻辑/红利股息/利率），有书面理由才微调
3) 定了就别反复改参数——平台内全是噪声，反复改才是亏损之源
六、诚实预期
· 前向：年化 5~7%；正常年份回撤 -6~-12%
· 尾部：2008式极端 -30~-34%（26年仅2次：2000科网-30%、2008-34%）
· 定投建仓期最坏浮亏 -27%（2007大顶情形）；一般 -1~-7%
· 别按回测高值规划生活；心理按「最坏-34%」准备，危机来了不卖
